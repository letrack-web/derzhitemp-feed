# derzhitemp-feed

Файл со всеми выпусками подкаста «Держи темп» для страницы [academymarathon.ru/podcast](https://academymarathon.ru/podcast).

Раз в час GitHub сам читает ленту Mave (https://cloud.mave.digital/36668), собирает
`docs/episodes.json` и публикует его по адресу
https://letrack-web.github.io/derzhitemp-feed/episodes.json.
Страница на Тильде при открытии берёт выпуски из этого файла.

В файле для каждого выпуска: номер, название, короткое описание, дата, длительность,
сезон, ссылка на страницу в Mave, обложка и темы.

## Файлы

| Файл | Что в нём |
|---|---|
| `config.js` | Ручная разметка: темы для отдельных выпусков (`MANUAL`) и список «★ Популярно» (`POPULAR`). |
| `classify.js` | Правила автоматических тем: какие слова в названии и описании дают какую тему. |
| `build.js` | Сборщик: читает ленту Mave и пишет `docs/episodes.json`. |
| `.github/workflows/update.yml` | Расписание: каждый час, а также после правки `config.js`, `classify.js` или `build.js`. |
| `docs/episodes.json` | Готовый файл для сайта. Руками не правится — его пересобирает GitHub. |

## Как поправить темы выпуска

1. Найдите guid выпуска — это id аудиофайла в Mave, часть ссылки `…/episodes/<guid>.mp3`.
   Его же видно в `docs/episodes.json` (восьмое поле у выпуска).
2. Откройте `config.js` → карандаш «Edit» и добавьте строку в `MANUAL`:
   `'<guid>': ['trail', 'academy'],` — список id тем из `classify.js`.
3. Сохраните (Commit changes). Через минуту-две файл пересоберётся, страница обновится.

Добавить выпуск в «★ Популярно» — вписать его guid в список `POPULAR` там же.

## Обновить прямо сейчас

Вкладка **Actions** → «Обновить выпуски «Держи темп»» → **Run workflow**.

## Если что-то сломалось

- Сборка не перезаписывает файл, если в ленте меньше 50 выпусков: сайт продолжит показывать последний удачный вариант.
- Если файл с GitHub не загрузится за 8 секунд, страница покажет 10 свежих выпусков напрямую из ленты.
- Ошибки сборки видны во вкладке Actions (красный крестик у запуска).
